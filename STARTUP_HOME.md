# Startup, New Tab and Home

Startup (`startupMode/startupUrl`), New Tab (`newTabMode/newTabUrl`) and Home (`homeMode/homeUrl`) remain independent per-profile settings. Fresh Startup and New Tab use Soulu; existing custom, blank and continue choices are preserved. `+`, Ctrl+T and Overview use New Tab; Alt+Home uses Home in the current tab. No extra toolbar button is added. Existing session restore keeps ordered normal tabs and selection, excludes private tabs, and is not crash/history/scroll restoration.

`soulu://home` resolves through the existing internal navigation architecture to the exact packaged `ui/home.html`. It does not register a global protocol or run a localhost server. HTML, CSS, JS, Onest fonts, canonical browser logo and provider icons are bundled. The minimal page contains the logo, a search capsule with provider and microphone, and top-right weather and favorites triggers. It has no dashboard, widgets, inline settings or editor. The local shell and typing remain usable offline.

Home search defaults to Google and offers exactly Google and Perplexity. The Home choice is persisted independently from the omnibox engine, using the shared native address parser with a provider override. Direct web addresses are navigated directly; other text is encoded as a provider query. Keyboard focus moves to the Home input on foreground Home creation, without stealing a later Ctrl+L address-bar focus. Background Home tabs do not take native focus. Native characters arriving before Home finishes loading are buffered for the foreground input; Ctrl+L clears that pending focus and buffer.

Home's scoped bridge accepts only its exact main document and originating native tab. It exposes Home state, selected bookmark favorites, navigation, weather and voice actions; it cannot access passwords or arbitrary shell commands. Strings are rendered with textContent, URLs are validated natively, and CSP excludes remote scripts, connections, objects and forms. Images can load origin favicons without a referrer, with a bundled fallback; no third-party favicon service is used.

Favorites reference ordered IDs from the existing bookmark model and the originating profile. New profiles are empty. Management uses the ordinary Settings apply/cancel flow; Home contains no editing tools. Legacy Home shortcuts migrate into real profile bookmarks without deleting their old data, preserving order and reusing existing URLs. Private provider/settings changes stay in memory and are discarded on final private-tab closure. Private favorites read the captured source profile's selected bookmarks.

Weather uses the originating CEF request context and fixed HTTPS Open-Meteo geocoding/forecast endpoints. Automatic mode is unavailable until the user allows Home location through ordinary Settings and Windows location access is available. It uses Windows Geolocator, rounds coordinates to approximately one kilometer, and never silently substitutes a city. Configured mode uses the user's saved city. The compact trigger opens current temperature, condition, high/low, feels-like, wind, humidity, precipitation and five following forecast days. Attribution appears inside the popover.

Requests have bounded bodies, redirect rejection and timeouts. A shared per-profile/configuration cache deduplicates requests; fresh data lasts 15 minutes, bounded stale data lasts at most 24 hours, and failed requests back off for 60 seconds. Normal cache writes use the existing atomic profile writer. Private cache stays in memory and is cleared on final private-tab closure. Tabs create no weather refresh timers or observers. Open-Meteo's free endpoint is for noncommercial usage; its terms must be reassessed if Soulu becomes commercial.

Voice requires the existing native Home microphone permission and honors Windows denial. WinMM captures mono 16 kHz PCM in memory, bounded to 15 seconds with silence termination. A brief initial calibration sets the noise floor before Home announces listening, accommodating quiet microphones while rejecting steady background noise. The microphone is closed before local CPU inference. Home distinguishes microphone preparation, active listening and recognition, and reports speech that could not be heard or recognized separately from unavailable capture. Pinned Whisper.cpp v1.8.2 and the multilingual tiny model recognize the application's RU/EN language. The bundled model is SHA-256 verified at build and before inference; licenses accompany the package. No audio upload, transcript logging or user recording file is created. Cancellation, tab switch, navigation and tab closure invalidate the job. The test-only native inference entry point requires the explicit regression environment and is never exposed to the web bridge.

`test-cef-home-pages.py` covers page intents, provider routing, focus, offline assets, bookmark favorites, profiles, private state and persistence. `test-cef-home-design.py` covers native screenshots, layout/theme/language and renderer-scale matrices, microphone denial/cancel and real weather/cache. Renderer scaling does not establish physical monitor DPI correctness. `test-cef-home-speech.py` verifies actual native inference using attributed public RU/EN speech; it does not establish physical microphone operation. `test-cef-home-focus.py` uses actual Windows mouse/Unicode keyboard input immediately after + and Ctrl+T, then checks Ctrl+L and late loading. `test-cef-home-migration.py` checks native legacy choice preservation, real bookmark conversion, restart idempotence and independent fresh-profile defaults. Native data tests cover weather schema, TTL, stale fallback and hard expiry. The release also retains the existing broader CEF regression suites. Test implementations are not evidence of passing runs; reports come from executed candidates.

Voice-qualified quiet PCM receives a bounded gain of at most 32× toward a 0.5 peak before inference; loud input is unchanged. The original capture and the in-memory working copy are both securely cleared. Local recognition has a 60-second inference deadline, checked by the backend abort callback. A deadline failure returns the ordinary unavailable state, frees the model and clears the captured samples; a user cancellation remains distinct.

Native tab thumbnails capture the existing viewport without a screenshot clip/scale override. Chromium temporarily changes and later restores the view size for clipped screenshots; that restoration can race a tab switch and a native Main/Classic layout change, leaving Home at the former viewport height. Overview still scales the image, and the existing 2 MB per-image / 24 MB aggregate limits remain. See Chromium's [PageHandler capture/restoration implementation](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/content/browser/devtools/protocol/page_handler.cc). The retained native layout suite checks real viewport dimensions after tab switching and mode changes.

The engine remains CEF 154.0.33+ga03e714 / Chromium 154.0.8037.94.
