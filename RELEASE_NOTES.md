# Soulu 1.0.74

- В «Настройки → Расширения» встроен менеджер расширений Chromium.
- Добавлены Chrome Web Store и локальная установка распакованных расширений из папки с manifest.json.
- Управление расширениями использует выбранный профиль Soulu.
- Добавлена Windows-проверка установки MV3 через настоящий выбор папки, работы скрипта в обычной вкладке, сохранения после перезапуска и включения/выключения.

Совместимость зависит от расширения. Действия, требующие панели Chrome, а также вход и автозаполнение Bitwarden пока не подтверждены. Полная совместимость с расширениями Chrome не заявляется.
