# Soulu 1.0.70

Исправлен импорт данных из сторонних браузеров.

- Обнаружение каналов Chrome/Edge/Brave Beta, Dev, Canary, современных профилей Opera, Opera Air, Firefox Developer Edition, LibreWolf, Waterfox, Floorp и Zen.
- Поиск профилей с нестандартными именами и без записи в profiles.ini; учёт корпоративного UserDataDir для Chrome/Edge.
- Ручной выбор общей папки User Data или Profiles добавляет найденные в ней профили в список источников.
- Исправлено чтение файлов открытого браузера: согласованная копия SQLite и WAL/журнала без изменения исходных данных. Если источник занят записью или запрещает чтение, предлагается закрыть его и повторить.
- Закладки, история, автозаполнение, поддерживаемые сессии и доступные пароли сохраняются в выбранный профиль Soulu. Защищённые пароли Chromium, которые нельзя расшифровать штатно, по-прежнему переносятся через CSV-экспорт.
- Существующие данные сохраняются, повторный импорт исключает дубликаты.

В релизе только установщик EXE и ZIP. Отчёты проверок — в артефактах Actions.
