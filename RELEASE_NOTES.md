# Soulu 1.0.68-beta

- Исправлено обрезание подсказок вкладок. Меню приложений больше не выбирает YouTube при открытии мышью.
- Выпадающие списки внутренних страниц оформлены в стиле Soulu, включая диалоги и управление с клавиатуры. У стрелок увеличен отступ справа.
- VPN автоматически распознаёт VLESS и Sudoku. В настройках VPN появился список сайтов для прямого подключения, включая их поддомены.
- В «О Soulu» доступны версии Xray/Sudoku, проверка стабильных и предварительных выпусков, установка выбранного тега и откат. Загрузка проверяется по SHA-256; предыдущий компонент сохраняется отдельно.
- Встроен VOT 1.12.3 для русской озвучки YouTube. Перевод включён по умолчанию; элементы управления находятся на видео. Настройки, субтитры, громкость, горячие клавиши и вход в Яндекс доступны в «Чтение и перевод → Video Translate».
- В релиз прикладываются только установщик EXE и портативный ZIP. Отчёты и диагностические изображения сохраняются в артефактах GitHub Actions.

CEF 156.0.14 / Chromium 156.0.8078.48. В комплекте Xray v26.10.21 и Sudoku v0.5.2.0.
