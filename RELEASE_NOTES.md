# Soulu 1.0.61-beta

- Единый установщик CONNECT Installer на Go/Wails; общий исходник хранится в `sanderstripa/connect/installer-core`.
- Кнопка «Принять и установить» находится на том же уровне, что в VPN, в обеих темах и на обоих языках.
- Сохранены установочные адаптеры, настройки и особенности продукта из проверенных пользователем локальных сборок.
- Изменения интерфейса и функциональности самого приложения не вносились, кроме номера версии.

Пользователь подтвердил установку всех пяти предыдущих локальных сборок. Автоматические проверки текущей сборки указаны в GitHub Actions; повторная ручная установка каждого финального SHA не заявляется.

# Soulu Beta 1.0.60 — новая иконка браузера

Старая иконка Soulu заменена эмблемой по предоставленному образцу.

- Новый векторный оригинал и прозрачные PNG во всех используемых размерах, от 16 до 1024 пикселей.
- Обновлены все ICO-варианты, значки браузера, внутренних страниц и первого запуска.
- Новая эмблема используется в установщике, деинсталляторе, ярлыках рабочего стола и меню «Пуск», окнах браузера и на панели задач.
- При обновлении заменяются также старые файлы иконок, используемые прежними ярлыками; новые ярлыки получают новый путь для обновления кэша Windows.
- Исправлен тест обновления с опубликованной версии 1.0.59; архив предыдущей версии проверяется по SHA-256.

Функции браузера, интерфейс, профили, импорт, VPN и настройки сохраняются. CEF 154.0.33 / Chromium 154.0.8037.94 остаются прежними.
