# Soulu 1.0.62-beta

Обновление движка со стабильной ветки 154 на последнюю доступную стабильную сборку Windows x64:

- CEF 156.0.14+g4fa4ab5.
- Chromium 156.0.8078.48.
- Единый дистрибутив заголовков, wrapper, библиотек и runtime; проверка SHA-1 архива и SHA-256 компонентов сохранена.
- Проверки версии при компиляции, запуске и через DevTools обновлены согласованно.

Интерфейс и функции браузера сохраняются. Результаты Windows-сборки и регрессионных проверок публикуются в GitHub Actions; непроведённые ручные проверки не считаются пройденными.
