# Soulu 1.0.67-beta

Матовая панель теперь размывает содержимое сайта вместо рабочего стола. При открытии страница начинается ниже панели; эффект появляется при прокрутке. Верхняя часть панели почти непрозрачна, нижняя мягко растворяется поверх страницы.

При выключенном матовом режиме панель полностью непрозрачна в светлой и тёмной теме. Переключение режима и вкладок сохраняет страницы без перезагрузки. Закреплённые элементы сайта остаются доступны ниже панели браузера.

Сохранены основная и компактная панели, адаптивное сжатие вкладок и анимация раскрытия. Движок: CEF 156.0.14 / Chromium 156.0.8078.48.
