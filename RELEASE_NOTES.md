# Soulu 1.0.65-beta

Добавлен отдельный третий режим панели — «Адаптивная». Включается в Настройки → Интерфейс → Режим панели.

С одной вкладкой адресная строка находится в центре просторной панели. Со второй вкладкой она плавно поднимается, а ниже появляется общий округлый ряд вкладок по образцу Safari на iPhone. При возврате к одной вкладке ряд сворачивается. Переход занимает 200 мс, с учётом системного ограничения анимаций Windows. Область сайта движется синхронно с панелью; существующие страницы, формы и прокрутка не перезагружаются.

При нехватке места неактивные вкладки уменьшаются до значков. Активная сохраняет значок, название и кнопку закрытия; закрепления, профили и инкогнито поддерживаются. Подсчёт вкладок относится только к видимому профилю или приватному сеансу.

Основная компактная и классическая панели сохранены как самостоятельные режимы.

Движок: CEF 156.0.14 / Chromium 156.0.8078.48.
