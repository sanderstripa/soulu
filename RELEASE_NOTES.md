# Soulu Beta 1.0.59 — Browser Import 2.0

Импорт из другого браузера теперь находится в одном компактном окне Settings 2.0.
Источники обнаруживаются автоматически, каждый профиль выбирается отдельно;
данные можно перенести в существующий или новый профиль Soulu.

- Закладки переносятся с папками, история — с датами посещений.
- Доступные пароли переносятся в защищённое хранилище Windows. Для защищённых
  исходных записей предусмотрен штатный CSV-экспорт из браузера.
- Переносятся адреса и значения автозаполнения; использовать их можно через
  меню поля «Заполнить из Soulu…». Платёжные данные исключены.
- Поддерживаемые сессии Chromium и Firefox восстанавливаются как вкладки.
  Для защищённых файлов сессий предусмотрен импорт HTML-списка адресов.
- Повторный импорт пропускает дубликаты. Выполнение, отмена и результат
  показываются в том же окне. Исходные профили сохраняются.

CEF 154.0.33 / Chromium 154.0.8037.94 остаются без изменения.
