Sona 0.13.0 Preview

Исправления по отзывам о Preview 12:
- Восстановлено название Sona в интерфейсе, установщике, Windows и путях; сохранены профили Preview 12.
- Убраны старый ярлык приватного просмотра и оставшиеся варианты иконок движка.
- После импорта остаётся одна активная кнопка OK.
- Исправлены цвета полей в тёмной теме мастера.
- Автоматическая погода использует разрешённую системную геолокацию и, при её недоступности, приблизительное определение города по IP через IPWhois. Прогноз предоставляет Open-Meteo.
- VPN в мастере: одно поле ссылки и подтверждение. Исправлен формат ключей и чтение старых записей в настройках.
- Сообщения об ошибках не переходят между разделами настроек.
- Стандартные рекламные закладки движка больше не создаются.
- Автоматические страницы расширений при запуске переносятся во вкладки основного окна.
- Значок расширений по умолчанию выключен; пустое меню показывает «Нет расширений».

В релиз включаются результаты целевых проверок Windows.
