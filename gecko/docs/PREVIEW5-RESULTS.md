# Sona Gecko Preview 5 — Windows x64

Распакуйте ZIP целиком и запускайте **Sona.exe**. Имя запускающего файла стабилизировано для ярлыков и внешних ссылок. Установленные Firefox и CEF не нужны. Данные остаются в `%LOCALAPPDATA%\SonaGecko\Profiles`; профили Preview 4 не сбрасываются. Основная ветка не изменялась.

## Проверки

Подтверждены реальные изменения Places и перенос между папками, сохранение закладок/избранного после перезапуска, пиксельное содержимое миниатюр, отображение изображений в обзоре, читаемые подсказки без favicon, первый запуск/пропуск мастера, запрос настоящего GitHub Releases из кнопки «О Sona», работа браузерного канала внешних ссылок и отказ неверному токену.

При настоящем движении указателя по панели видео продолжало воспроизводиться, а размеры viewport и положение видео не менялись. При эмуляции масштабов Gecko 1 / 1,25 / 1,5 / 2 и двух размерах окна зазоры между родительской областью браузера и веб-контентом составили 0 px. Это не заменяет проверку физических мониторов с разным Windows DPI.

Сравнение с настоящей CEF beta-1.0.76 при клиентской области 940×640: геометрия панели — 0 px, настройки — до 2 px. Сравнение Onest и Segoe UI приложено в снимках; базовый Onest сохранён для соответствия текущему Sona. Шрифты веб-страниц не менялись.

Реальный локальный Whisper распознал русское «Погода» и английский фрагмент речи JFK. На универсальной CPU-сборке общего Windows runner обработка каждой записи заняла около 14 секунд. Низкая задержка голосового ввода на всех компьютерах не заявляется; захват физического микрофона, акустика и Windows-разрешение требуют ручной проверки на устройстве.

Проверены подпись VOT, установка после согласия, включение и отключение; сохранены 36 проверок нативных расширений, включая действие на настоящей странице, activeTab, popup в extension-процессе, закрепление после перезапуска, приватность и запрет внедрения в служебные file-страницы.

Итоговые машинные отчёты входят в пакет: `preview5.json`, `speech5.json`, `vot5.json`, `extensions.json`, `windows-final5.json`, `mica-final5.json`, `visual-comparison.json`. Проверка запуска после распаковки выполняется отдельно и публикуется как `zip-smoke.json`. BUILD.json содержит точный исходный коммит и сведения о сохранённых исполняемых компонентах.

## Ограничения

- YouTube на адресе CI потребовал «Войдите в аккаунт, чтобы подтвердить, что вы не бот». readyState=0 и currentTime=0. Поэтому настоящее воспроизведение русской озвучки VOT **не подтверждено**. Наличие установленного расширения не засчитывается как успех перевода. Диагностика приложена в youtube-vot-diagnostic.json. Проверка нужна на обычном подключении с воспроизводимым видео.
- VOT обращается к внешним серверам Яндекса/VOT; это явно показано до установки. Он не подменяет локальный перевод страниц и не устанавливается без согласия. Необязательная отправка технических данных не выдаётся автоматически.
- Голосовой ввод реализован локально, но фактическая запись с физического микрофона не сертифицирована CI. Универсальная CPU-конфигурация сохранена ради совместимости; ускорение распознавания остаётся отдельной задачей.
- У обновлений нет независимого подписанного манифеста и транзакционного установщика с автоматическим откатом. Доверие к источнику опирается на TLS, официальный репозиторий и digest GitHub; отдельная SHA-256 рядом с ZIP не объявляется криптографической подписью. Доступны проверка и скачивание, автоматическая установка отключена. Профили находятся вне папки программы, поэтому предыдущую распакованную версию можно сохранить для ручного возврата.
- Native Firefox Add-ons остаётся штатным менеджером расширений со стилизацией; универсальная совместимость со всеми XPI/native-host приложениями не заявляется. Специальные page_action-кнопки внутри адреса и Chrome CRX не интегрированы.
- Content scripts расширений намеренно запрещены на file://, чтобы защитить служебный мост Sona; это затрагивает и другие локальные HTML-файлы.
- CEF-заморозка вкладок и отдельные настройки экономии, не имеющие готовой интеграции Gecko, остаются отключёнными. «Оптимизировать» использует штатную выгрузку Gecko и не запускается при активных загрузках; активные/звучащие/захватывающие вкладки исключаются.
- Все физические GPU/драйверы, сочетания Windows DPI и произвольные внешние VPN-серверы не сертифицированы. VPN/Rust бинарные компоненты сохранены без изменений из принятой Preview 4 Update 1.

Firefox Fission, многопроцессная архитектура, песочница, HTTPS-проверки и проверка подписи расширений не отключались. Интерфейсный мост доступен только пяти точным установленным страницам Sona, а не обычным сайтам.
