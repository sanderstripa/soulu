# Soulu Gecko Preview 8 — Windows x64

Выпуск распространяется установщиком **Soulu-Gecko-Preview-8-Setup-win64.exe**. Интерфейс и общий код установщика взяты из той же закреплённой версии installer-core, которую использует Soulu CEF. Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\Programs\SouluGecko`; CEF-версия и установленный Firefox не заменяются. Закройте работающую Soulu Gecko перед установкой. Профили остаются в `%LOCALAPPDATA%\SouluGecko\Profiles` и не удаляются при удалении программы.

| Исправление | Фактическая проверка |
|---|---|
| Одно начальное окно и нормальное закрытие | Запуск настоящего `Soulu.exe`, повторный запуск, восстановление двух сохранённых окон в одно с сохранением страниц обоих окон, закрытие через `WM_CLOSE`, завершение процесса launcher. Синхронный `DwmFlush` удалён с потока интерфейса. Явно открываемые позднее окна и приватные окна не объединяются. |
| VOT — встроенный компонент | В новом профиле компонент действительно зарегистрирован как `isBuiltin` и активен. Он отсутствует в пользовательском списке Soulu и списке дополнений. Состояние ранее отключённого компонента сохраняется. Управление остаётся в разделе перевода; подписанный пакет не изменён. |
| Переключатель расширений | Проверено реальное изменение ширины/видимости кнопки после выключения и включения из настроек. При `hidden` CSS больше не оставляет кнопку видимой. |
| Менеджер дополнений | Кнопка открывает установленные расширения. Проверено совпадение изображения логотипа с ресурсом Soulu, вертикальное выравнивание поиска и положение всей внутренней страницы ниже панели браузера. Матовый эффект применяется к HTTP/HTTPS-сайтам, а не внутренним страницам. |
| Home после редактирования закладки | Проверена последовательность: открытая боковая панель → редактор → флажок «Избранное на Home» → сохранение → настоящий указательный клик по Home. Избранное открывается, боковая панель остаётся открытой. Область перехвата кликов ограничена верхней и левой панелями. |
| Меню действий страницы | Измерено положение под кнопкой адресной строки: нижний край кнопки 39 px, верх меню 47 px при общей высоте панели 88 px. Меню больше не отодвигается ниже всего ряда вкладок. |
| Локальная Home | Убрана имитация сетевой загрузки для Home, добавлена предварительная загрузка изображений, исключена ненужная инициализация элементов выбора. Наблюдаемая готовность четырёх новых Home на стенде — 203–312 мс, включая опрос теста. Нулевое время открытия не заявляется. |
| Состояние приветствия | Настройки при открытии получают свежий снимок; сохранение параметров больше не возвращает устаревшее состояние незавершённого приветствия. |
| Обновления | Текущая версия — Preview 8. Проверен отказ предлагать собственный установщик и выбор установщика следующей версии. Загрузка сохраняет проверку официального адреса, SHA-256 и формата Windows x64; автоматического запуска скачанного EXE нет. |
| Установщик и версия | Проверены видимая версия `0.8.0-preview8` на экранах приветствия, настроек, установки, завершения, обновления и удаления; версия ресурсов EXE — `0.8.0.0`. При первом установленном запуске браузер сообщает Preview 8 и использует собственный Gecko runtime. |
| Сохранение данных при установке | Выбранные язык и тема применяются к новому профилю. Повторная установка сохраняет существующие настройки и настоящую закладку в Places. Удаление убирает программу и сохраняет профиль. Проверено отсутствие изменения системного прокси. |

**Результат: 41 целевая проверка прошла** — 6 проверок окон, 12 интерфейса, 4 первого видимого окна и 19 полного цикла установщика. Дополнительно прошли проверки компонентов установщика и отказа принимать повреждённый исполняемый файл в payload.

Проверенные исходники браузера и установщика: `a94114bd475eadeed99703faec0c4c4df3214ec3`.

- [Сборка и полный цикл установщика](https://github.com/sanderstripa/soulu/actions/runs/41834120080)

В выпуск включается именно проверенный EXE без повторной сборки при публикации. JSON-отчёты, контрольная сумма и манифест сборки приложены к выпуску.

Границы проверки: чистый профиль Preview 7 на стенде сам по себе не воспроизвёл исходные два окна. Поэтому отдельно проверены повторный запуск и профиль с двумя сохранёнными окнами; теперь он восстанавливается в одно без потери страниц. Зависание на конкретном драйвере пользователя не воспроизведено; потенциально блокирующее ожидание DWM удалено, нормальное закрытие и завершение процесса проверены. Результаты Windows-стенда не являются обещанием одинакового времени запуска на любом оборудовании.

VPN Xray/Sudoku, Rust AdBlock, NSS, импорт, профили, авторизация, локальный перевод и ускоренный голосовой помощник не переносились заново. Исполняемые компоненты движка, VPN, AdBlock, модели речи и подписанный XPI сохранены из принятой сборки; отдельно обновлён launcher с оригинальной иконкой и версией 8. Повторные проверки сторонних учётных записей, реального микрофона, внешних VPN-подключений и публичного YouTube voice-over в этот целевой прогон не входили. VOT использует внешние сервисы Яндекса/VOT; перевод страниц остаётся локальным.

Работа выполнена только в `gecko-preview`; `main` не изменена.
