# Sona Gecko Preview 7 — Windows x64

Распакуйте весь ZIP и запустите `Sona.exe`. Установщик не требуется. Данные существующих профилей не сбрасываются: `%LOCALAPPDATA%\SonaGecko\Profiles` остаётся отдельно от Firefox и Sona CEF.

Исправления:

- Первый запуск: отключены оба штатных предварительных окна Gecko. Основное окно показывается после готовности настоящих элементов Sona, передачи слоёв из процесса интерфейса и синхронизации композитора Windows. Нет отдельной заставки, второго браузера или постоянного цикла снимков экрана.
- Приветственная страница: устранена гонка с начальной навигацией Gecko; новый профиль получает Sona Welcome, завершённая настройка сохраняется.
- Адаптивная панель: переход к одной вкладке рассчитывается плавно в процессе интерфейса по общей временной шкале. Конечная позиция адресной строки проверена в обычном и развёрнутом окне; настройка уменьшенного движения Windows сохраняет своё действие.
- Избранное Home: редактор читает актуальные сохранённые ID; устаревший снимок настроек не перезаписывает новые изменения. Проверены сохранение нескольких сайтов, немедленное обновление открытого Home, настоящий клик при открытой панели закладок и сохранность после перезапуска.
- Home получает общий снимок погоды из памяти/дискового кэша до показа. Исправлены гонки запросов при смене настроек. Локальные элементы показываются после начального состояния, шрифтов и основных изображений.
- Матовая панель действительно размывает содержимое страницы, продолженное под панелью; прозрачность переходит в непрозрачность к границе контента. Переключатель меняет реальные пиксели. Обои Windows/Mica не используются вместо страницы.
- Нативные фоновые поверхности согласованы с темой. На Windows проверены края при изменении размера в светлой и тёмной темах.
- Расширения: существующая иконка пазла Sona, общий список действий, переключатель в элементах панели. Переключатели расширений реально включают/отключают их; выключенные остаются доступными для управления. Пользовательское расширение удаляется через принятый штатный менеджер дополнений.
- Устаревший uBlock Origin из экспериментальной реализации удаляется однократно после готовности встроенного Rust AdBlock. Собственный Rust-блокировщик остаётся компонентом браузера. Существующий Bitwarden сохраняется как пользовательское расширение, с однократным включением при миграции; хранилище расширения не удаляется.
- VOT регистрируется в настоящем встроенном расположении Gecko, не является удаляемым пользовательским расширением. Проверены активность и сохранение регистрации после перезапуска. Исходный подписанный пакет и прежнее согласие на внешние сервисы сохраняются.
- Переходы в настройки из менеджера дополнений направляются в Sona. Проверены настоящая кнопка менеджера и отсутствие вкладки настроек Firefox. Нативные ресурсы названия продукта используют Sona; лицензии Mozilla сохранены.
- Preview 7 согласован в EXE, интерфейсе и BUILD.json. Настоящая проверка GitHub сообщает об установленной последней версии и не предлагает скачать собственный ZIP.

Проверки выполнены на Windows x64 в [GitHub Actions](https://github.com/sanderstripa/soulu/actions/runs/41793966683), исходники `5cda9c644f157b256502c1ab068dc7c7642ff7a0`: **54 целевые проверки прошли** (27 основных, 9 расширений, 4 первого окна, 14 краёв при изменении размера). JSON-отчёты приложены к выпуску и включены в каталог `Preview7-validation`.

Измерения: максимальное перемещение адресной строки за наблюдаемый кадр — около 1,4 CSS px, конечный центр — 34 px. Первое рабочее видимое окно в отдельном запуске — около 2,6 с; 12 захваченных видимых кадров содержали элементы Sona. Нулевое время запуска не заявляется. Видео тестовой страницы продолжало воспроизведение без изменения размеров/положения страницы при перемещении мыши по панели.

Упаковка использует именно проверенный артефакт без повторной сборки компонентов. Публикация выполняется только после дополнительной проверки реального `Sona.exe` из распакованного ZIP в пути с пробелами и изолированном профиле, с проверкой пути собственного Gecko runtime. Результат — `zip-smoke.json`.

Границы проверки: результаты относятся к указанному Windows-стенду и перечисленным сценариям, а не ко всем сочетаниям драйверов и оборудования. Повторный полный аудит всех ранее принятых функций не выполнялся. VPN, Rust AdBlock, NSS, импорт, профили, локальный перевод и ускоренный голосовой помощник сохранены; существующие EXE/DLL/модели/XPI проверены на неизменность при наложении ресурсов (отдельно пересобран только launcher с оригинальной иконкой и версией 7). Реальные сторонние учётные записи, физический микрофон и публичный YouTube voice-over в этом прогоне не проверялись. VOT использует внешние серверы Яндекса/VOT и требует прежнего согласия; перевод страниц остаётся локальным. Автоматическая замена установленной сборки не добавлена — обновления распространяются ZIP-архивом.

Работа опубликована исключительно в `gecko-preview`; `main` не изменяется.
