Soulu 0.14.0 Preview

Исправления по отзывам о Preview 13:
- Системная тема использует единое значение Windows для панели и страниц браузера.
- Удаляются оба варианта локализованных ярлыков «Приватный просмотр», включая повреждённые.
- Скрытое окно подготовки не создаёт промежуточную кнопку на панели задач.
- Показ окна больше не ожидает кадрового события скрытого окна.
- Завершение последнего окна закрывает собственный VPN helper перед выходом процесса.

Включены результаты проверок обеих системных тем, запуска, закрытия после работы с VPN helper и повторного запуска, установки и удаления.
