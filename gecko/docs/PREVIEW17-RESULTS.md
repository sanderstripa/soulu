Sona 0.17.0 Preview

Исправлен лаунчер, выдававший «The profile is starting or busy»: существование Windows mutex ошибочно считалось владением профилем. Ожидающие запуски сами удерживали объект и не могли стать новым владельцем после выхода предыдущего сеанса. Теперь используется настоящее владение mutex и передача его следующему запуску.

- Проверена очередь из 50 нажатий во время закрытия, без ожидания полного выхода старого процесса.
- Если loopback-связь недоступна, обычный ярлык активирует только существующее окно своего профиля через Windows.
- Оставшиеся собственные процессы после закрытия окон больше не удерживают сеанс бесконечно. Открытые/свёрнутые окна и другие профили не завершаются.
- Данные профиля и прежние исправления сохраняются.

В релиз включены результаты проверок Windows.
